# AgriCart - Agricultural Marketplace Platform

**AgriCart** is a Flutter mobile marketplace connecting farmers, buyers, and agribusinesses in the Philippines. A complete e-commerce solution for agricultural products with real-time chat, order tracking, payment processing, and seller analytics.

## 🌾 What is AgriCart?

A digital marketplace platform that makes it easy for farmers to sell their products and buyers to purchase fresh agricultural goods directly from local producers. Built with Flutter and Django.

## ✨ Key Features

- 🛒 Product browsing with search and filters
- 💬 In-app messaging between buyers and sellers
- 📦 Order management with real-time tracking
- 💳 Payment integration (COD, GCash, Maya, Bank Transfer)
- 📊 Seller analytics dashboard
- 📱 Push notifications
- 🖼️ Image handling via MongoDB GridFS

## 🛠️ Tech Stack

- **Frontend**: Flutter (BLoC Architecture)
- **Backend**: Django REST API
- **Database**: Firebase Firestore
- **Image Storage**: MongoDB GridFS
- **Payments**: PayMongo
- **Notifications**: Firebase Cloud Messaging

## 📱 Target Users

Farmers | Local Buyers | Suppliers/Traders | Agribusinesses

---

**Product Categories**: Fresh Produce | Livestock & Poultry | Seeds & Fertilizers | Farm Tools | Processed Goods
